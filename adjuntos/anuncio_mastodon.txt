Hoy os presento algo que me tiene enamorado: GitHub Accesible, una aplicación de escritorio para Windows con la que se maneja GitHub entero y git local desde el teclado y con lector de pantalla, ya sea NVDA, JAWS o Narrador. Todo en español, gratuita y de código abierto con licencia GPL. Me encanta, de verdad, y quiero contaros por qué.

Es chupada, como para un bebé. La abres, inicias sesión y ya está. Pero no os confundáis: es potente hasta para quien domina GitHub de arriba abajo. Lo sencillo es sencillo y lo avanzado está ahí cuando lo necesitas, sin pelearte con páginas web llenas de botones sin etiqueta.

Iniciar sesión es facilísimo: con el navegador y un código que la aplicación te copia y te deletrea, sin escribir tu contraseña nunca en la aplicación. También con un token de acceso personal, importando la sesión de GitHub CLI o con las credenciales guardadas de Git. Admite varias cuentas a la vez y GitHub Enterprise Server. Los tokens se guardan cifrados con tu usuario de Windows.

La ventana principal tiene a la izquierda las secciones y a la derecha su contenido: Inicio con la actividad de quien sigues, Notificaciones, Mis repositorios, Repositorios con estrella, Mis issues, Mis pull requests, Gists, Organizaciones, Proyectos, Repositorios locales, Repositorios vigilados, Seguidores, Personas que sigo, Codespaces y Resultados de la búsqueda. Te mueves por las secciones sin que el foco salte solo: entras al contenido cuando tú quieres.

Cada repositorio se abre en su propia ventana con absolutamente todo: código con navegación por carpetas y ramas, issues, pull requests, discusiones, GitHub Actions, releases, ramas, etiquetas, commits, proyectos, hitos, colaboradores, seguridad, secretos y variables, webhooks, reglas, estadísticas, Pages y configuración.

Issues y pull requests con la conversación completa, comentar, responder citando, reacciones, etiquetas, asignados, hitos, cerrar y reabrir. En los pull requests puedes revisar línea a línea, aprobar o pedir cambios, leer los hilos de revisión, ver los checks y fusionar.

Tiene un visor de diferencias pensado de verdad para lector de pantalla: te dice si cada línea se añade, se quita o se queda igual, con su número, con sonidos distintos para cada tipo y con teclas para saltar de cambio en cambio, de bloque en bloque y de archivo en archivo.

GitHub Actions al completo: ejecuciones, trabajos y pasos, registros limpios donde saltas de error en error con F8, volver a lanzar todo o solo lo que falló, lanzar flujos a mano y descargar artefactos.

Git local también, y completo: ver cambios, preparar y confirmar, historial, ramas, stash, etiquetas, remotos, submódulos, traer, tirar, enviar y sincronizar, clonar con el progreso hablado y hasta resolver conflictos bloque a bloque eligiendo tu versión, la otra o ambas. Además genera claves SSH y te ayuda con la configuración de git.

El buscador es una maravilla: busca repositorios, código, issues, pull requests, usuarios, commits, temas y discusiones, con todos los filtros de GitHub explicados en español, te enseña la consulta que se va formando, te muestra dónde coincide cada resultado, guarda tus búsquedas y el historial, y hasta te trae las tendencias del día, la semana o el mes.

Las notificaciones llegan en segundo plano con voz, con sonido y, si quieres, con aviso de Windows. Desde la lista las marcas como leídas o hechas, las silencias o vas directo a lo que las motivó.

Y la accesibilidad es el corazón de todo. En las listas eliges qué se lee y en qué orden: puedes leer columna a columna con las flechas o ir directo a una con Control y un número, elegir qué columnas ver en cada lista, cómo se anuncian las casillas y qué sonidos suenan para cada cosa. Cada pantalla tiene sus letras de acceso sin repetirse, Control+H te explica el control donde estás, F1 abre el manual y Mayúsculas+F1 la lista de teclas.

Escribes en un editor de Markdown con vista previa y que guarda borradores solo, para que no pierdas nunca un comentario largo.

Es portable: la descomprimes donde quieras y todo lo que guarda se queda en su carpeta. Se actualiza sola con paquetes firmados y verificados, y tú eliges si desde mi servidor, desde GitHub, desde los dos o desde una dirección propia.
