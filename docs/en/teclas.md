# GitHub Accesible keyboard shortcuts

Throughout the application, choosing something (a section, an option in a drop-down list) does not move the focus: you decide when to go to the content. All windows share a few basic keys: Ctrl+H explains the control that has the focus, F1 opens the user guide and Shift+F1 opens this list. Lists also have their own common keys (see below). The menus show the keys next to each command.

## Main window

- F6: switch between the section list and its content.
- Enter or Tab in the section list: go to the content. Moving through the sections does not change the focus.
- The section's keys that don't need a selected item also work in the section list (Ctrl+Shift+A, Ctrl+N, Ctrl+F, Ctrl+Shift+J...).
- Alt+1 to Alt+9 and Alt+0: go to each of the first ten sections.
- F5: refresh the section.
- Ctrl+O: open a repository by name or link.
- Ctrl+E: search GitHub.
- Ctrl+U: view the profile of a user or organization (suggests the one in the selected row).
- Ctrl+Shift+N: new repository.
- Ctrl+Shift+K: clone a repository.
- Ctrl+Shift+G: open a local git folder.
- Ctrl+Shift+L: sign in with another account.
- Ctrl+Shift+U: switch account.
- Ctrl+P: Preferences.
- Ctrl+Shift+H: history of spoken messages.
- Ctrl+Shift+O: command palette (also in the other windows).
- F1: user guide. Shift+F1: keyboard shortcuts.
- Ctrl+Q: exit.

## Global hotkeys (from any program)

You can change them in Preferences, Global hotkeys.

- Ctrl+Alt+Shift+G: show or hide the application.
- Ctrl+Alt+Shift+N: read out the unread notifications.
- No default key: open Notifications, search GitHub and check notifications now.

## All lists

- Up Arrow and Down Arrow: move to another item (the screen reader reads the row).
- Left Arrow and Right Arrow: read the columns one by one.
- Ctrl+1 to Ctrl+9: read that column directly.
- Enter: open the item.
- Applications key or Shift+F10: actions menu for the item.
- F5: refresh. Ctrl+M: load more items.
- Ctrl+F: filter the list. Ctrl+Shift+F: clear the filter.
- Ctrl+C: copy the row. Ctrl+Shift+C: copy the link.
- Ctrl+B: open in the browser. Ctrl+I: all the details.
- Ctrl+J: sort by the column being read (ascending, descending and back to the original order). Ctrl+Shift+J: choose the column and the direction. Clicking the column header also works.

## Main window sections

- Notifications: Ctrl+L mark as read, Ctrl+Shift+A mark all as read, Delete mark as done, Ctrl+Shift+S mute the conversation, Ctrl+Shift+R go to the repository, F4 change the filter.
- Repositories: Ctrl+K clone, Ctrl+S star, Ctrl+N new repository, Delete delete, F4 change the filter.
- My issues and My pull requests: F4 change the filter, Ctrl+Shift+R go to the repository.
- Gists: Ctrl+N new, Delete delete, F4 switch between mine, starred and public.
- Local repositories: Ctrl+N add a folder, Ctrl+K clone, Ctrl+Shift+E open the folder, Delete remove from the list.
- Search results: Ctrl+Shift+P view the owner, Ctrl+Shift+R go to the repository, Ctrl+K clone, Ctrl+S star, F4 new search, Ctrl+Shift+B open the search on the web.

## Repository window

- F6: switch between sections and content. Moving through the sections does not change the focus.
- Ctrl+Tab and Ctrl+Shift+Tab: next and previous section.
- Alt+1 to Alt+9: the first nine sections.
- F5: refresh. Ctrl+W: close the window (Escape does not close it).
- Ctrl+Shift+P: view the profile of the repository owner.
- In the sections: Enter open, Ctrl+N create, F2 change or rename, Delete delete, F4 change the GitHub filter.
- Code: Backspace goes up one folder, F4 switches branch, Ctrl+P finds a file in the whole tree, Ctrl+U uploads a file, Ctrl+S downloads the file.
- Issues and pull requests: Ctrl+R comment, Ctrl+L labels, Ctrl+Shift+A assignees, Ctrl+Shift+X close or reopen.
- Pull requests and branches: Ctrl+D view the differences or compare.
- Actions: Ctrl+R re-run, Ctrl+N run a workflow, Ctrl+Shift+W notify me when it finishes.
- Commits: Ctrl+Shift+S copy the identifier (SHA).
- Wiki: Enter read the page, F2 edit it, Ctrl+N new page, Delete delete it, Ctrl+P search all pages.

## Issue

- In the conversation: Enter view as HTML, Ctrl+N comment, Ctrl+R quote reply, F2 edit, Delete delete, Ctrl+E react, Ctrl+C copy, Ctrl+B browser, F5 refresh.
- Ctrl+Shift+E edit title and description, Ctrl+Shift+L labels, Ctrl+Shift+A assignees, Ctrl+Shift+M milestone, Ctrl+Shift+B browser, Ctrl+Shift+C link.
- Ctrl+W close.

## Pull request

- Ctrl+Tab: switch tab (Conversation, Commits, Files changed, Checks, Review threads).
- Alt+V or Ctrl+Shift+R: review (approve, request changes or comment).
- Alt+M or Ctrl+Shift+F: merge.
- In Files changed, pressing Enter on a line comments on it.
- Ctrl+W close.

## Diff viewer

- F8 and Shift+F8: next and previous group of changes.
- Ctrl+F8 and Ctrl+Shift+F8: next and previous hunk.
- F7 and Shift+F7: next and previous file.
- Ctrl+G: go to a line.
- Ctrl+T: view everything as text.
- Ctrl+C: copy the line.
- Ctrl+D: what changes within the line.
- Ctrl+Shift+D: summary of the differences.
- Ctrl+Shift+T: view the narrated differences.
- Enter: comment on the line (in pull requests). Ctrl+Enter: read its comments.

## Repository file

- Ctrl+G go to a line, Ctrl+L read out the current line.
- Ctrl+F find, F3 and Shift+F3 next and previous.
- Ctrl+E edit, Ctrl+S download.
- Ctrl+Shift+C permanent link, Ctrl+Shift+B browser.
- F5 refresh, Ctrl+W close.

## GitHub Actions run

- F5 refresh, Ctrl+R re-run all jobs, Ctrl+Shift+R only the failed ones.
- In the log: F8 and Shift+F8 next and previous error or warning; Ctrl+F find; F3 and Shift+F3 repeat the search.
- In Jobs, Enter takes you to the log; in Steps, Enter takes you to its part of the log.
- In Artifacts: Enter download, Shift+Enter choose the folder, Delete delete.
- Ctrl+B browser, Ctrl+Shift+C link, Ctrl+W close.

## Release

- F7 formatted notes, Ctrl+U upload assets, Ctrl+E edit.
- In Assets: Enter download (and verify the SHA-256 checksum), Shift+Enter choose the folder, F2 rename, Delete delete.
- F5, Ctrl+B, Ctrl+Shift+C and Ctrl+W.

## Gist

- Enter edit the file, F2 rename, Delete delete, Ctrl+N add a file.
- Ctrl+S star, Ctrl+M comments, Ctrl+K copy the clone address.
- F5, Ctrl+B, Ctrl+Shift+C and Ctrl+W.

## Discussion

- Ctrl+N comment, Ctrl+R reply, Ctrl+M mark as answer, Ctrl+U upvote, F7 view formatted.
- F5, Ctrl+B, Ctrl+Shift+C and Ctrl+W.

## Project

- Ctrl+M move to (change the status), F2 change a field.
- Ctrl+N add a draft, Ctrl+Shift+N add an issue or pull request.
- Ctrl+Shift+A archive, Delete remove from the project, Enter open.
- F4 filter, Ctrl+Shift+F clear the filter.
- Ctrl+G group; with the list grouped, Ctrl+Down Arrow and Ctrl+Up Arrow jump between groups.
- F5, Ctrl+B, Ctrl+Shift+C and Ctrl+W.

## Local repository (git)

- F6 switch between sections and content; Ctrl+Tab switch section (from the section list, the focus stays there).
- Enter or Tab in the section list: go to the content. Moving through the sections does not change the focus.
- Ctrl+R refresh the status, Ctrl+W close.
- Ctrl+Enter in the message: commit.
- Git menu: Ctrl+Shift+T fetch, Ctrl+Shift+U pull, Ctrl+Shift+P push, Ctrl+Shift+Y sync, Ctrl+Shift+G open on GitHub, Ctrl+Shift+R create pull request, Ctrl+Shift+E open the folder, Ctrl+Shift+K open a console.
- Changes: Space or Enter stage or unstage, Ctrl+A stage all, Ctrl+Shift+A unstage all, Ctrl+D view differences, Delete discard, Shift+Delete delete an untracked file.
- History: Enter differences, Ctrl+N branch here, Ctrl+E tag here, Ctrl+Shift+C copy the SHA, F4 filter, Shift+F4 clear the filter.
- Branches: Enter switch, Ctrl+N create, F2 rename, Delete delete, Shift+Delete delete the remote one.
- Tags: Ctrl+N create, Delete delete, Ctrl+E push to the remote.
- Stash: Enter view, Ctrl+N save, Ctrl+L apply, Ctrl+Shift+L apply and delete, Delete delete.
- Remotes: Ctrl+N add, F2 change the address, Delete delete, Ctrl+T fetch from that remote.
- Submodules: Ctrl+U update. Conflicts: Enter resolve block by block.

## Resolve conflicts block by block

- Alt+P and Alt+N: previous and next block.
- Alt+Y, Alt+O, Alt+F and Alt+R: keep your version, the other one, both (yours first) or both (the other first).
- Alt+X: write the result by hand; Alt+D: apply it.
- Alt+U: undo. Alt+S: save and mark as resolved.
- Escape: close (asks first if there are changes).

## Text editor

- Ctrl+Enter: send.
- F7: formatted preview.
- Alt+F: attach text files, such as logs (in issues, pull requests, discussions and comments).
- Tab and Shift+Tab: next and previous control. If Preferences, Editor, “The Tab key types a tab character” is on, Tab types a tab character and Ctrl+Tab moves between controls.
- Escape: close (offers to save a draft).
